# Portfolio application

[Visit Dongyun Kim’s portfolio](https://dongyunkim.vercel.app/)

This directory contains the React application and contact API. See the [repository README](../README.md) for featured projects, UX details, setup, testing, and deployment instructions.

## Quick start

Requires Node.js 24 and npm. From this directory:

```sh
npm ci
npm start
```

## Verify

```sh
npm run build
node node_modules/react-scripts/scripts/test.js --watchAll=false --runInBand
```

Project content: `src/data/projects.js`
Project button styles: `src/components/Projects/ProjectActions.css`
Shared styles: `src/style.css`
